# 铁军铮骨 · 家国丹心

叶挺将军生平互动展厅。React + Vite + D3，采用本地中国及世界地图数据，覆盖三个时期、20 个核心事件。以电脑浏览、投影课堂展示为主，适配平板和手机。

界面采用鲜明红金配色，搭配红绸、五角星和宝塔山装饰。网页各入口统一使用红色五角星标识；图片说明与史料补充默认折叠，素材出处保存在本地目录中。

封面采用全屏山河晨光、红绸与历史原照融合的电影序章构图，加入《囚歌》节选“我应该在烈火和热血中得到永生！”。已进入过展厅的会话，可访问 `/?cover=1` 再次查看封面；点击入场后恢复正常会话记忆。

封面轮播九张现有历史原照，每3秒切换，以0.8秒叠化与小幅推进呈现，一轮约27秒；支持暂停、前后翻阅和左右方向键。手动翻阅后暂停自动播放，切到后台暂停，返回后接续。遵循“减少动效”设置，此时仅手动切图。只保留当前与过渡照片两层，预加载下一张；失败照片跳过，全部失败时保留背景与入口。宽幅艺术背景使用 imagegen 生成，桌面／手机分别加载本地 WebP，原照片未作 AI 改绘；背景说明和完整提示词见 [生成记录](docs/generated-cover.json)。

## 本地运行

需要 Node.js 20.19+ 或 22+。同步 Word 文案和运行文案校验还需 Python 3（仅用标准库）。

```bash
npm install
npm run dev
```

访问终端给出的地址（默认 `http://localhost:5173`）。同一局域网设备可通过该电脑的 IP 和端口访问。地图、历史照片和配乐随项目提供；打开外部史料链接时需要联网。请通过 HTTP 服务访问，不能直接双击 `index.html`。

```bash
npm run build
npm run preview -- --port 4173
```

生产文件位于 `dist/`。部署时保留 `images/`、`audio/` 和 `data/` 目录；当前配置使用网站根路径。

运行 `npm run package:site` 可生成经过文件完整性校验的 `release/yeting-site.zip`。部署包、服务器目录及平台构建设置见 [部署说明](docs/DEPLOYMENT.md)。实际网址和访问范围在选定托管平台后配置。

## 生平分期

1. **1896—1927年：投身革命、铁军建功。** 包含求学、北伐及南昌、广州两次起义，共9个节点。
2. **1928—1937年上半年：辗转求索、丹心不改。** 包含留苏、旅欧、澳门生活和迁沪，共4个节点。
3. **1937年下半年—1946年：抗战与坚守。** 包含延安、新四军、囚禁、重新入党及遇难，共7个节点。

分期依据人物经历，以1937年7月全面抗战爆发为第二、三篇章边界，消除旧标题对1937年的重叠。详见页面“史料文献 → 生平分期依据”和 [SOURCES.md](docs/SOURCES.md)。

## 参观方式

网页首先显示密码页，固定密码为 **yanan**（区分大小写）。验证通过后进入原有封面，同一标签页会话内记住验证结果；分享链接也先验证，再打开对应事件。支持显示／隐藏密码、回车提交和错误提示。

这是前端入口验证，不是服务器认证；静态资源及浏览器收到的代码仍可直接查看。若需真正限制公开访问，应在托管平台或服务器配置访问控制。密码维护位置为 `src/AccessGate.jsx`，修改后重新构建部署包。

- 首次进入可选择“开启声音并进入”或“静音进入”；入场页每个浏览器会话出现一次。分享链接直接进入对应展签，例如 `/?event=rejoin`。
- 顶部切换三个时期，点击地图标记或底部时间轴直接阅读事件。桌面地图占首屏约 78%；展签关闭保留当前视角。
- 地图支持拖动、滚轮缩放、按钮缩放、中国地图与海外足迹切换、当前事件定位和复位。聚集地点使用引线避让；引线末端的细点是地理位置，编号圆点便于点击。
- 金色箭头按当前视图中的编号顺序连接圆点，同城事件也保留连线。密集节点适当分散，路线避开其他圆点、标签和连线；跨过当前视图未显示的编号时使用虚线。路线和编号位置随地图等比缩放，不在缩放结束后重新选路；圆点、文字和箭头大小保持稳定，箭头停在圆点外沿。
- 点击“海外足迹”先打开三站选择列表与欧亚地图，再选择1924年留苏、1928年再赴莫斯科或旅居欧洲。列表和地图均可打开对应展签；可一键返回中国地图，保留此前视角。第二篇章从海外经历开始，默认显示海外列表。
- 图文展签使用 Word 主稿中的分节正文、逐段引用和 1—3 张关联图片。点击引用编号展开标题、机构／作者、日期及原文链接。
- 点击图片放大，通过缩略图或放大视图中的箭头翻阅。缺失图像不影响图注和正文。
- 点击地图左下方“延安印记”打开延安事件，可翻阅宝塔山、杨家岭旧址等关联图片。
- 自动导览每站停留 10 秒，仅展示简短标题并移动地图。点击事件、操作地图、切换时期或进入后台会暂停导览，之后手动继续。
- “精神丰碑”和“史料文献”打开独立面板；右上角设置提供音乐播放／暂停、音量、全局静音、交互音效、减少动效与路线开关。

## 结语：铁军精神 · 山河新篇

地图右下方的独立悬浮标签“观看结语”、最后一个事件的“观看结语”按钮，以及自动导览完成第20站，均进入结语准备画面。点击“开启声音并播放”或“静音观看”后开始；准备页不会下载或自动播放歌曲。

完整播放 `music/` 中的原曲，时长约2分40秒，以“烽火铸魂、自立奠基、科技强军、强军新篇”四篇章呈现20张真实照片。每张约8秒、约1秒叠化；34句歌词由本地 Stable-ts 对原文和音轨强制对齐，随演唱滚动，高亮当前句。前奏、间奏及尾奏不提前高亮。歌曲自然结束后定格“传承铁军精神 / 矢志强军报国”，可以重新播放或返回展厅。

- 播放、暂停、静音、音量、进度拖动与跳至结尾均在底部；空格播放／暂停，左右方向键跳转5秒，Esc返回。焦点位于按钮或滑杆时保留其原生键盘操作。
- 结语准备、播放及定格期间，原展厅配乐和提示音保持挂起；退出后恢复原声音状态、地图视角和选中事件。切到后台暂停结语，返回后需主动继续。
- 减少动效时关闭运镜与叠化，歌词即时换行；图片失败保留上一张或背景，歌曲失败提供重试。最多两张过渡照片，仅预加载后两张。
- 保留原有9张老照片，按国防发展历程补入原子弹、东方红一号、银河一号、1999年阅兵、神舟五号、2012年辽宁舰及北斗三号。2007年仪仗队退出播放，国防科大的“银河—天河”成果前后呼应；已知年份依次推进，照片图注仅显示“年份＋内容”，日期不详的历史资料保留范围说明。出处见[20张照片目录](docs/epilogue/PHOTOS.md)，歌词制作与时间边界见[歌词时间轴](docs/epilogue/LYRICS.md)。

网页运行只依赖静态素材，不需要 Python、Stable-ts 或模型。原MP3与歌词Word保持不变；需要重新制作歌词时间轴时，使用 `scripts/align-epilogue.py`，生成候选时间轴后复核，勿直接覆盖已校对的运行数据。完整验收、关键截图和原速播放记录见[结语交付说明](docs/epilogue/README.md)。

## 声音与可访问性

音乐只有在主动开启后播放，默认音量 20%；阅读时降至该音量的 40%，关闭展签恢复。页面进入后台暂停音乐，回到前台恢复此前仍处于播放意图的音乐；用户主动暂停后不自动恢复。音频失败会显示提示，仍可继续阅读。

支持系统“减少动态效果”偏好及展厅开关；阅读中停止装饰动画。手机关闭微粒，电脑微粒最高24帧/秒；拖动地图、阅读展签及后台时停止。系统字体无需联网下载。

- 时期标签：左右方向键、Home、End。
- 地图：Tab 聚焦，方向键平移；标记使用 Enter 或空格打开。
- 展签：Esc 关闭，左右方向键切换事件。
- 图片放大：左右方向键切图；Esc 先返回展签，再按一次关闭展签。
- 弹窗和图片浏览保持 Tab 焦点循环；关闭后返回触发按钮。

## 地图性能

拖动、缩放及导览定位使用单帧合并的 SVG 图层变换，移动过程不触发 React 对整张地图的重渲染；静态地形复用。中国地图优先加载，世界数据首次打开海外足迹时加载并缓存。取消高开销的地图滤镜，移动中暂停路线与光晕装饰，缩短定位动画。同机4倍 CPU 限速下拖动帧间隔中位数由68.1 ms降至16.6 ms；测量条件、局限和复测命令见 [验收记录](docs/ACCEPTANCE.md)。

路线避让只在节点布局变化时计算，以最小缩放比例预留间距；缩放复用固定路线，平移仅移动整个路线图层。上一轮箭头避让更新后的生产预览在4倍 CPU 限速下，拖动帧间隔中位数为16.6 ms、P95为17.5 ms；这是单次本机测量，早于本轮缩放稳定性修复。

## 验证

```bash
npm test
npm run test:ui
npm run build
```

浏览器测试使用 Playwright，默认 Chrome 路径为 `/usr/bin/google-chrome`。其他环境可设置 `CHROME_PATH`，例如 `CHROME_PATH=/path/to/chrome npm run test:ui`。测试会启动或复用 5173 端口的 Vite 服务。

自动化覆盖 20 个地图标记和时间轴展签、前后切换、图片放大、焦点、分享直达、地图视角保持、10 秒导览、五种视口宽度、真实音频播放／静音／后台暂停、减少动效和资源失败。正式展陈前可在所使用的投影设备与音箱上调整显示亮度和音量。
