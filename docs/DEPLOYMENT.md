# 部署说明

项目是纯静态网站，生产文件位于 `dist/`，包含地图数据、历史图片、艺术示意图和完整配乐。运行时不需要 Node.js、数据库或后端接口。

## 当前交付物

- `release/yeting-site.zip`：最新生产部署包，解压后直接得到 `index.html`、`assets/`、`images/`、`data/`、`audio/` 等文件。
- `release/yeting-site.sha256`：压缩包校验值。
- `release/yeting-site-manifest.json`：构建时间、文件清单和逐文件校验值。

这些是准备部署的本地文件；生成部署包不等于网站已经上线。部署目标、域名及访问范围需要按实际平台设置。

## 重新生成

在项目根目录运行：

```bash
npm ci
npm test
npm run package:site
```

需要 Node.js 20.19+ 或22+、Python 3.9+。打包脚本先核对入口文件以及全部素材，再生成 ZIP。每次修改网页后重新执行打包，使用 `release/yeting-site.zip`，避免上传旧的 `yeting-life-atlas/` 副本。

## 上传到静态网站平台或学校服务器

本次部署包适用于网站根路径，例如 `https://展厅域名/`。将 ZIP 的内容解压到网站目录，让 `index.html` 直接处于站点根目录，保持所有子目录结构。服务器应对目录请求提供 `index.html`，正确返回 JavaScript、CSS、JSON、图片和 MP3 文件。

平台若直接从源代码构建，使用以下设置：

| 设置项 | 值 |
|---|---|
| 项目目录 | 项目根目录 |
| 安装命令 | `npm ci` |
| 构建命令 | `npm run build` |
| 发布目录 | `dist` |
| Node.js | 22 |
| 环境变量 | 无必需项 |

站点首页和事件分享使用查询参数，例如 `/?event=prison`，无需额外配置前端路由回退。请仅上传构建产物，不要将整个项目目录作为网站根目录。

如果部署地址包含子目录，例如 `https://学校域名/yeting/`，需要同时调整构建基础路径以及地图、图片、音乐的运行时请求路径，不能只改发布目录或只改 Vite 的 `base`。

部署后的访问范围由平台或服务器控制。局域网部署需使用内网地址；需要登录后访问时，应在托管平台或反向代理配置访问控制。网页现有固定密码入口（yanan）在浏览器端验证，适合简单的访问提示，不是服务器认证。代码和静态素材仍可直接访问，真正的访问限制需要托管平台或服务器实施。

## 本地验收

```bash
npm run preview -- --port 4173
```

访问 `http://localhost:4173/`，先输入密码 yanan，再检查入场、三个时期、海外足迹、事件弹窗和主动开启音乐。分享链接在首次访问时也必须先通过密码页。部署完成后还应在正式地址验证 `/?event=prison` 直达、手机访问和资源加载。

`vite preview` 只用于本地验收，正式网站应交给静态托管平台或生产 Web 服务器。构建与发布目录依据 [Vite 官方静态部署说明](https://vite.dev/guide/static-deploy.html)。
