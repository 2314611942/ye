## 生平分期

按叶挺个人经历划分：1896—1927年为求学、北伐及两次起义；1928—1937年上半年为旅居与归国求索；1937年下半年—1946年为全面抗战、囚禁与重获自由。1937年以7月全面抗战爆发为界。 这是根据人物经历采用的策展分期，不作为唯一的标准分法。将两次起义纳入第一篇章，能连续呈现求学、北伐与革命武装实践；第二篇章集中表现旅居和归国求索。20 个事件及分享 ID 保持不变。依据：[叶挺：在烈火和热血中永生](https://www.zlb.gov.cn/2021-06/16/c_1211203544.htm)、[叶挺的清廉人生](https://dangshi.people.com.cn/n/2014/0107/c85037-24044363.html)、[新四军军部在武汉成立始末](https://www.81.cn/js_208592/jdt_208593/10119362.html)。
