## 校对过程

1. 对34句原文作整曲强制对齐，保留原始词级结果：[alignment-raw.json](alignment-raw.json)。
2. 运行Stable-ts边界精炼，留存比对：[alignment-refined.json](alignment-refined.json)。精炼可能截短歌曲长音，因此不直接覆盖全部结果。
3. 对起唱、主歌衔接、两遍副歌和尾声作独立窗口重对齐，记录：[alignment-anchors.json](alignment-anchors.json)。采用首句26.78秒边界，第8句结束50.66秒，尾声最后两句134.38—140.68秒、141.50—147.82秒。其余句子保留整曲词级对齐边界，未采用平均分配。
4. 逐项比对Word原文、重复副歌、先后关系、无重叠及前奏/间奏/尾声留白，并用独立识别输出交叉检查起唱和停顿。此记录为模型对齐与文本/时间核对，不冒称人工逐字听审；课堂播放前可结合下表试听复核长音边界。

播放器以音频currentTime为唯一时钟。句末到下一句起唱之间不高亮，前奏约26.78秒，最后一句后保留原曲尾奏至160.44秒。图片按8秒一张编排，与演唱字幕的非均匀句长分别配置。
