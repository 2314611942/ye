# 结语交付说明

“铁军精神 · 山河新篇”全屏结语已按国防建设历程更新。封面、密码页、地图和20个事件的Word文案继续使用原有内容。

## 参观流程

地图右下方的独立悬浮标签“观看结语”、最后一站展签的“观看结语”、自动导览第20站停留结束，均打开准备画面。用户选择开启声音或静音后开始完整歌曲。歌词、四篇章、20张照片与进度统一跟随音频时间；结尾显示“传承铁军精神 / 矢志强军报国”，一直停留，支持重播与返回。

原展厅配乐与提示音在准备、播放和定格期间挂起，返回后恢复原播放意图及音量。结语进入后台自动暂停，回到前台不自动继续；静音观看同样依靠真实音频时钟推进。返回保留地图视角、缩放与选中事件，不自动重启导览。

## 内容文件

- [34句歌词时间轴](../../src/epilogue-lyrics.json)：`start / end / text`；从原Word提取，不含段落标题，保留两遍副歌。
- [歌词对齐记录](LYRICS.md)：Stable-ts整曲对齐、边界精炼和窗口重对齐结果；逐句文字、边界、重复副歌及间奏检查。这里记录机器对齐与时间核查，未将其表述为人工听审。
- [20张照片目录](PHOTOS.md)：真实影像的题名、日期、作者／机构、来源、许可及图像辨析。
- [照片配置](../../src/epilogue-photos.json)：顺序、每张8秒、桌面与手机位置、完整主体显示设置。本轮播放照片约2.53 MiB，尺寸未强行放大；未用AI改绘历史事实。
- [原速播放记录](playback-check.json)：Chrome完整播放160.44秒音轨，捕获20张照片、全部34句和四篇章，最多同时两层照片，音频自然结束后暂停并显示标语。

保留原有9张历史照片，7张后期照片更换为国防发展节点。“烽火铸魂”保留叶挺、新四军及军民支前；“自立奠基”从1949年开国走到1964年原子弹、1970年东方红一号；“科技强军”连接1983年银河一号、1999年阅兵、2003年神舟五号、2012年辽宁舰与2015年天河二号实拍；“强军新篇”接2018年歼-20、2020年北斗三号、2021年南昌舰及2025年受阅坦克。图注只显示年份和内容，未详日期不补造年份。完整出处及照片年代与成果年代的区别见照片目录。

2007年仪仗队退出播放，国防科大成果改以“银河—天河”两张真实影像贯穿。旧素材保留在项目，旧目录存于 [previous-photos.json](previous-photos.json)，不会在当前结语预加载或播放。

## 运行与复核

网站保持纯静态部署，运行步骤见[项目说明](../../README.md)。部署包为 `release/yeting-site.zip`，由 `npm run package:site` 构建和逐文件校验；须部署到站点根路径。

```bash
node scripts/epilogue-catalog.mjs
npm test
npm run test:ui
npm run package:site
```

浏览器测试包含7种结语视口：1920×1080、1440×900、1024×768、768×1024、390×844、320×740、844×390。测试播放失败、浏览器拒绝播放、全部照片失败、单张失败后续恢复、音量静音、进度与键盘、后台暂停、焦点循环、地图状态保持及原配乐互斥。

在开发服务已启动时导出关键截图；设置 `ALL_FRAMES=1` 可保存全部40张逐图截图：

```bash
PREVIEW_URL=http://127.0.0.1:5173 node scripts/epilogue-preview.mjs
PREVIEW_URL=http://127.0.0.1:5173 node scripts/epilogue-playback-check.mjs
```

第二条命令真实播放约2分40秒，不使用加速、伪造 `ended` 或跳到最后一秒代替完整验证。浏览器检查默认 `/usr/bin/google-chrome`，可通过 `CHROME_PATH` 配置。对齐模型仅是制作工具，网站部署不携带模型或Python环境；课堂展示时可根据音箱与投影设备试听并调整音量。
