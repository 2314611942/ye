### 处理及使用说明

- 大图长边不超过 1600 px，缩略图长边不超过 420 px；历史原照与遗址今照仅等比例缩放与 JPEG 压缩，没有补绘、修复或移除原照片中的署标。封面和入口卡片以 CSS 裁切、叠色呈现，展签大图保持完整画面。原图质量有限时保留实际清晰度。
- 历史照片许可依据各 Commons 文件页的公共领域标记；现代摄影各自的 CC0、CC BY-SA 3.0 或 4.0 许可保留在本目录，未把整个项目宣称为同一许可。
- 1921 年军官照为文献中的低清扫描；人物依文件页从左向右列出。
- “叶挺人物照片”不晚于 1941 年，不能据其名称误标成少年、军校或留苏照片。
- 1940 年干部合影年份采用文件元数据。1939 年的家庭、军部合影不作为 1927 年起义、1928 年旅欧或 1938 年岩寺现场照片。
- 页面使用国防科技大学校徽替代文字署名，不显示素材作者或授权文字；本目录留存素材出处。延安素材元数据见 [yanan-metadata.json](yanan-metadata.json)。既有 Commons API 元数据存放在 [archive-metadata.json](archive-metadata.json)；既有肖像使用对应的 Ye Ting.jpg 文件页。

## 封面

暗红与旧金色纪念海报构图，使用本目录中的叶挺历史肖像，经 CSS 等比例显示、叠色与边缘渐隐；没有修改原照片。题字、山河剪影和延安意象采用 CSS / SVG，不增加视频或持续动画。封面采用 Word 主稿《囚歌》节点中的“我应该在烈火和热血中得到永生！”一句，按三行排版，标注“叶挺《囚歌》节选”；并核对 [《学习时报》转引](https://cpc.people.com.cn/n1/2022/1104/c443712-32558750.html)。
