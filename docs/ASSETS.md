### 处理及使用说明

- 大图长边不超过 1600 px，缩略图长边不超过 420 px；历史原照与遗址今照仅等比例缩放与 JPEG 压缩，没有补绘、修复或移除原照片中的署标。封面和入口卡片以 CSS 裁切、叠色呈现，展签大图保持完整画面。原图质量有限时保留实际清晰度。
- 历史照片许可依据各 Commons 文件页的公共领域标记；现代摄影各自的 CC0、CC BY-SA 3.0 或 4.0 许可保留在本目录，未把整个项目宣称为同一许可。
- 1921 年军官照为文献中的低清扫描；人物依文件页从左向右列出。
- “叶挺人物照片”不晚于 1941 年，不能据其名称误标成少年、军校或留苏照片。
- 1940 年干部合影年份采用文件元数据。1939 年的家庭、军部合影不作为 1927 年起义、1928 年旅欧或 1938 年岩寺现场照片。
- 页面使用红色五角星作为统一装饰标识，不显示素材作者或授权文字；本目录留存素材出处。延安素材元数据见 [yanan-metadata.json](yanan-metadata.json)。既有 Commons API 元数据存放在 [archive-metadata.json](archive-metadata.json)；既有肖像使用对应的 Ye Ting.jpg 文件页。

## 封面

全屏电影序章构图，轮播本目录中的九张历史原照：叶挺肖像、1921年军官合影、人物照片、中将军服照、1938年与斯诺合影、1939年军部及两张家庭合影、1940年干部合影。按各自元数据显示题名与年代，不将后期照片当作早年事件现场或将轮播作为严格编年。每3秒切换，0.8秒交叠，一轮约27秒；CSS 推进不超过1.5%、平移不超过0.5%，没有修改原照片。低清照片限制显示大小；支持暂停、手动翻阅、后台暂停与减少动效；同时最多保留两层照片，仅预加载下一张，失败照片跳过。

背景为本项目使用内置 imagegen 生成的山河、红绸与晨光艺术装饰，不含历史人物、文字或标志，不作为历史现场或地理复原；不计入18张展签影像。桌面 WebP 为117386字节、手机 WebP 为44254字节，仅作压缩与等比缩小。见 [桌面背景](../public/images/cover/epic-landscape.webp)、[手机背景](../public/images/cover/epic-landscape-mobile.webp)、[生成原图](generated-originals/epic-landscape.png)、[完整提示词与处理记录](generated-cover.json)。延安意象沿用 SVG 装饰。

封面采用 Word 主稿《囚歌》节点中的“我应该在烈火和热血中得到永生！”一句，按屏幕宽度排版，标注“叶挺《囚歌》节选”；并核对 [《学习时报》转引](https://cpc.people.com.cn/n1/2022/1104/c443712-32558750.html)。
